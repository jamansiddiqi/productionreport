One-time setup so it opens by itself:
1) In Chrome's download list click the small arrow next to the file and choose Always open files of this type (if it shows "Unverified download" click Keep first).
2) Windows: right-click an .eml file → Open with → Outlook → Always. (Use classic Outlook; Windows Mail / new Outlook may not open it as a draft.)
A web page cannot start Outlook by itself, these two settings make the download open automatically.
